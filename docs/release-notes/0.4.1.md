Flux 0.4.1 fixes what the first days on Windows turned up, takes files from Explorer and Finder,
and shows Claude's pictures in a popup.

## New

- **Files from Explorer and Finder.** Files copied there paste into the project tree
  (<kbd>⌘</kbd><kbd>V</kbd>, <kbd>Ctrl</kbd><kbd>V</kbd> on Windows), and files dragged from there
  drop into the folder under the pointer. It works the other way too: a file copied or cut in the
  tree pastes in Explorer and Finder. A name that is taken gets "copy" added, as with Copy in the
  tree.
- **Pictures in a popup.** A picture's thumbnail in the Claude chat or in the message box opens over
  the window: zoom, actual size, the arrows go through the message's pictures, <kbd>Esc</kbd> closes.
  **Open in Tab** keeps the picture in a tab, as before. Pictures zoom with a pinch on the trackpad,
  in the popup and in a picture's tab.
- **Files into Claude's message box.** Files copied in Explorer or Finder paste into the message box
  as dropped files do: pictures are attached, other files mentioned.
- **Claude's permission modes.** The mode menu offers Auto mode, where the model has it, and
  Bypass permissions — Claude then does everything without asking. <kbd>⇧</kbd><kbd>⇥</kbd> goes
  through Ask before edits, Accept edits, Plan mode and Auto mode, as in the terminal.

## Fixed

- **Windows: Flux didn't reopen the last projects.** Started from the Start menu, the taskbar or
  the installer, Flux took the folder Windows started it in for a project. Now, without a folder to
  open, it reopens the projects that were open when it quit.
- **Claude refused to edit in the "Don't ask" mode.** That mode refuses whatever isn't allowed in
  advance — easy to read as "go ahead without asking". It's no longer in the menu; a session started
  in it shows it as "Allowed only".
