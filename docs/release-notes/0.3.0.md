Flux 0.3.0 is about motion and calm: the interface moves — popups grow out of where you called them,
tabs and rows glide into place — and plugins stop asking for keychain access.

## New

- **Motion everywhere.** Popups, menus and dialogs grow out of where you called them and fade away;
  tabs, file tree rows, Git lists and the Tracker board glide into their new places instead of
  jumping; badges and counters bounce when they change; jumps in the editor (go to definition, the
  next match, Page Up/Down) glide, while typing and the caret stay instant. Turn it off in
  **Settings → Appearance → Interface → Animations**, or with Reduce Motion in macOS.
- **Country check for Claude.** Flux checks which country your connection comes from and stops
  Claude in the countries you list (Russia by default): if your VPN drops, no request leaves from
  there. The flag is in the status bar; **Settings → Claude Code → Country Check** holds the list.
- **Plugins keep their secrets in Flux.** Tokens and passwords of plugins now live in Flux's own
  encrypted file that only you can read — macOS no longer asks for keychain access after an update.
  Secrets saved by earlier versions move over once.

## Changed

- **Claude answers your `!` commands** by default: run a command with `!` in the chat and Claude
  replies to its output; <kbd>⌘</kbd><kbd>↵</kbd> runs it without an answer.
- **Quitting asks one short question** — "Quit Flux? All running processes will be stopped." —
  instead of one detailed warning per window.
- A plugin's form asked from its page in Settings (an organization's ID, another way to sign in)
  opens right over Settings.
- The board of a plugin scrolls along one axis at a time: scrolling down no longer slides it sideways.

## Fixed

- <kbd>⌘</kbd><kbd>Esc</kbd> didn't open the Claude console: a hidden macOS shortcut took it first.
  Flux turns that shortcut off while it runs.
- A long "Other…" answer to Claude's question ran past the edge of its row.
- A section of Settings could open already scrolled down.
- The problems widget of the scrollbar flickered on every save while a language server was busy.
