Flux 0.1.1 takes far less of your Mac: an idle window costs next to nothing, and a working Claude
Code session no longer keeps the processor and the graphics chip busy.

## Fixed

- **A plugin could keep a processor core busy for good.** When a plugin was reloaded or turned off
  while one of its web requests was on its way, the request never ended and spun on a core — every
  reload added another one. A cancelled request now ends at once.
- **An idle window kept drawing.** After a mouse move or a key press Flux went on redrawing its
  window 120 times a second, often for minutes. It now draws only when something changes, and keeps
  the full refresh rate only while you scroll, drag or type quickly.
- **Claude Code sessions are much lighter.** The pulsing dot of a working session redrew the whole
  window 120 times a second for as long as Claude worked. Pulses now run at 30 frames a second,
  streamed text lands in the same frames, and the editor and the project tree aren't laid out again
  for frames that don't change them.
- **The session history** is no longer read again in full every time a session changes its status.

On the Mac it was measured on: about 200% of a processor core and three quarters of the graphics
chip before; while Claude works — about 18% and a quarter; idle — next to nothing.
