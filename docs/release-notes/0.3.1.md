Flux 0.3.1 no longer asks for your keychain's password.

## Fixed

- **The first start of Flux 0.3.0 asked for the keychain's password.** Flux 0.3.0 moved the
  plugins' secrets from the macOS keychain into its own encrypted file, and macOS asked for the
  keychain's password to let Flux read and remove the old items. Flux no longer touches the keychain
  at all. If you update straight from 0.2.0, a plugin that kept a secret there asks you to sign in
  once more.
