The first public release of Flux — a fast, native code editor for macOS with a complete Git workflow
and Claude Code built in.

## What's inside

- **Fast and native.** Written in Rust and drawn by the GPU: Flux opens instantly, and typing,
  scrolling and searching never wait, even in files with tens of thousands of lines. Find a file by
  a few letters, search the whole project with a live preview, run any command from the palette.
- **Understands your code.** Errors as you type, completion, go to definition, find usages and
  rename — from language servers Flux installs by itself; **⌥↵** offers the
  quick fixes.
- **Git, all of it.** A commit window with changelists and partial commits, an editable
  side-by-side diff, branches in one popup, a three-way merge tool, a log with a graph, an
  interactive rebase and blame in the gutter.
- **Claude Code, built in.** A native chat (**⌘Esc**) on your own Claude
  subscription: every edit opens as a diff you accept or trim, and the changes of a session gather
  in their own changelist to review, roll back or commit.
- **Plugins in a sandbox.** Languages, color themes, file icons and integrations from the
  Marketplace in one click; plugins run as WebAssembly and reach only what you allowed.
- **A terminal built in**, split and searchable, with ⌘-click on `file:line`.
- **A welcome guide** on the first launch: the language, the theme, your languages' plugins,
  Claude Code and a few slides on working in Flux. Again any time: Help → Welcome Guide.

## Install

Download the `.dmg` for your Mac — **`macos-aarch64`** for Apple silicon (M1 and later),
**`macos-x86_64`** for Intel — open it and drag Flux to Applications. Flux needs macOS 12 or later.

Flux isn't notarized by Apple, so macOS blocks its first launch, saying it can't verify the app.
Once:

1. Open Flux and close the message.
2. Open **System Settings → Privacy & Security**, find the note that Flux was blocked and click
   **Open Anyway**.
3. Confirm with your password or Touch ID.

From then on Flux updates itself: it tells you when a new version is out, and **Update and
Restart** installs it — no more questions from macOS. Settings → Updates picks the channel:
Stable, or Beta for the versions still being tried.
