Flux 0.4.0 runs on Windows and understands frontend projects: Vue, Svelte, Astro and Angular
components are highlighted part by part, with their language servers, Tailwind CSS and ESLint.

## New

- **Flux on Windows** — Windows 10 (1903 and later) and 11, x64 and ARM64. The installer puts Flux
  in your user folder and needs no admin rights; updates come over the air, as on the Mac. Shortcuts
  follow Windows habits (<kbd>Ctrl</kbd> where the Mac has <kbd>⌘</kbd>, <kbd>Ctrl</kbd><kbd>Y</kbd>
  deletes a line, <kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>S</kbd> opens Settings, <kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>C</kbd>
  the Claude console); the title bar has the window buttons and the menu (<kbd>Alt</kbd><kbd>\</kbd>);
  the terminal runs PowerShell, `!` commands run in Git Bash. Git features need Git for Windows.
  The installer isn't signed: on the first run Windows SmartScreen says it protected your PC — choose
  **More info → Run anyway**.
- **Languages inside languages.** The scripts and styles of HTML, the code blocks and front matter
  of Markdown are highlighted in their own languages.
- **Vue, Svelte, Astro, Angular** (plugins in the catalog): every part of a component — the template
  with its expressions, `<script lang="ts">`, `<style lang="scss">` — is highlighted in its own
  language, and each framework's language server brings errors, completion and navigation. Angular
  templates are recognized by name (`*.component.html`).
- **Tailwind CSS and ESLint** (plugins in the catalog) work next to a file's own language server:
  Tailwind completes and explains classes, ESLint shows its problems with quick fixes. They start
  only in projects that use them.
- **.env files** (the Dotenv plugin): highlighting of keys, values and `${references}`, and checks —
  a key set twice, a file with values Git doesn't ignore, keys missing against `.env.example`.
- **Config files**: `.gitignore` and similar ignore files, `.editorconfig` and `.npmrc`; `.babelrc`,
  `.eslintrc` and other configs without an extension open as JSON.
- **Less** is highlighted, and served by the CSS language server.

## Changed

- A file may have helper language servers: their completion and hover join the main server's,
  their problems are shown next to its ones, navigation stays with the main server.
- Problems a server delivers on request (pull diagnostics) are shown — ESLint's among them.
- Plugin API 0.4: languages inside languages (`injections`), file name patterns (`file-patterns`),
  helper servers (`secondary`), servers started only where a project needs them (`activation`), and
  `{server-dir}`, `{root}` in a server's settings. Plugins built for 0.3 keep working.
